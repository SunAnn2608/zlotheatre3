Базовая вёрстка (HTML и CSS) выполнена мной вручную. Дальнейшая доработка до финального варианта велась с помощью генеративных нейросетей.

В реализации проекта были использованны следующие генеративные нейросети:
1. ChatGPT / Codex — генерация логики переходов, обработка кликов, отладка скриптов
2. GitHub Copilot — автодополнение кода, подсказки по синтаксису, ускорение написания повторяющихся блоков
